# UI-слой

Декларативная модель компонентов. UI описывается как дерево узлов, каждый из которых определяет компонент, его свойства, дочерние элементы и привязки.

← [Edem](./edem.md)

## Компонентный узел

Описывает один элемент UI:

- **Компонент** — имя (HTML-тег или зарегистрированный компонент)
- **Свойства** — параметры компонента (поддерживают шаблонные выражения)
- **Дочерние** — вложенные узлы, текст или перевод
- **События** — привязки к обработчикам

## Привязки событий

Три типа:

- **Flow** — запуск потока бизнес-логики
- **Action** — CRUD-операция над данными
- **Navigate** — навигация

## Привязки данных

Итерация по коллекции:

- Коллекция-источник
- Фильтры и сортировки
- Шаблон для каждого элемента

## Условная отрисовка

if / elseIf / else для условного отображения.

## Структурные элементы

- **Ссылки** — обёртка в навигационный компонент
- **Модальные окна** — обёртка в модальный контейнер
- **Телепорт** — рендеринг в другую часть DOM
- **Переходы** — CSS-анимации
- **Именованные слоты** — передача контента в layout-компоненты
- **Skeleton** — индикатор загрузки
- **Empty state** — состояние пустоты

## Шаблонный движок

Разрешение выражений `{{ expr }}` в свойствах и тексте. Контекст включает: параметры маршрута, функцию перевода, данные коллекций, обработчики событий.

## Ключевое свойство

Модель не привязана к конкретному UI-фреймворку. Одинаковые JSON-описания могут быть отрендерены на любом фреймворке (Vue, React, Svelte, или нативный DOM).

## Конкретные рендереры

JSON-дерево компонентов рендерится конкретным рендерером, который реализует фреймворк-специфичную логику. Рендерер отвечает за: разрешение шаблонных выражений в свойствах, маппинг событий (flow → запуск потока, action → CRUD, navigate → переход), условную отрисовку (if/elseIf/else), структурные элементы (teleport, transition, slots, skeleton, empty state). Один JSON — множество рендереров. Регистрация компонентов происходит через реестр: имя компонента в JSON → конкретный компонент фреймворка.

## Reactive Subscriptions

Подписки на изменения данных автоматически обновляют UI. Подписки привязаны к жизненному циклу компонентов и отписываются при уничтожении.
