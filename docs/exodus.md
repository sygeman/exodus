# Exodus

Десктоп-приложение — **IDE для построения Edem-приложений**. Визуальное программирование через манифесты.

## Что делает

Exodus позволяет создавать приложения, описывая их через JSON-манифесты. Вместо написания кода — разработчик определяет данные, логику и UI визуально.

Exodus сам является Edem-приложением (`build(exodus) = exodus`) — хранит свою собственную схему в SQLite и может собирать себя из манифестов.
